# Проверка самостоятельной установки перед выпуском

Это памятка для выпуска, не инструкция врачу. Незаполненные проверки не считаются пройденными.

## Проверка кандидата до публикации стабильного релиза

Инструкции врачу используют `main` и последний стабильный пакет. До публикации 0.2 не отправлять их как подтверждённый путь новой версии. При проверке кандидата использовать установщики из проверяемого коммита и пакет, собранный из того же коммита. Указать `MEDSCRIBE_BUNDLE_FILE` с локальным пакетом и контрольной суммой. Образы приложения и речи должны соответствовать этому кандидату; не подменять их предыдущим релизом.

В отчёте записать: SHA коммита, версию пакета, дайджесты образов, ОС, память, браузер, модель ИИ и время установки. Скриншоты изолированного интерфейса в инструкции показывают расположение полей; они не служат доказательством чистой установки.

## Обязательные сценарии

| Проверка | Windows | macOS | Linux |
|---|---|---|---|
| Чистая установка строго по странице своей ОС | Не проверено | Не проверено | Не проверено |
| Docker отсутствует / установлен, но остановлен | Не проверено | Не проверено | Не проверено |
| Мало памяти / мало места | Не проверено | Не проверено | Не проверено |
| Обрыв сети при скачивании и повтор установки | Не проверено | Не проверено | Не проверено |
| Повтор установки сохраняет аккаунт и тестовый черновик | Не проверено | Не проверено | Не проверено |
| Ярлык после перезагрузки, в том числе путь с пробелами | Не проверено | Не проверено | Не проверено |
| Код регистрации устарел → повторный запуск ярлыка | Не проверено | Не проверено | Не проверено |
| Реальная запись → распознавание → облачный протокол | Не проверено | Не проверено | Не проверено |
| Та же цепочка с qwen2.5:7b, записать характеристики компьютера | Не проверено | Не проверено | Не проверено |
| Диагностика без Docker / при неготовых службах | Не проверено | Не проверено | Не проверено |

Windows: отдельно проверить установку Docker для текущего пользователя и для всех пользователей. Docker может хранить данные на другом диске: проверка места папки программы не подтверждает размер свободного пространства виртуального диска.

Для диагностик: подставить тестовые секреты в ошибки Docker, ответы API, `.env` и название контейнера; ни один секрет не должен оказаться в файле. Не использовать настоящие данные пациента.

## Проверка на врачах

Три врача без опыта Docker/API, с охватом Windows и macOS. Дать только ссылку на START.md. Задание: установить, подключить ИИ, получить протокол вымышленной записи, открыть приложение после перезагрузки. Не помогать во время прохождения; записывать шаги остановки, время и вопросы. Если была подсказка — исправить инструкцию и повторить этот путь с новым участником.

Критерий выпуска с формулировкой «для самостоятельной установки»: все три участника завершили путь без подсказок автора, а обе схемы подключения ИИ проверены с настоящими службами. Клиническая оценка качества модели проводится отдельно.
