# Снимки для инструкции

Сняты с компонентов Setup и LlmSettingsCard из рабочей копии на основе 0.2.0-rc.8. Браузер, ширина 1280 px. Данные статуса имитированы, аккаунт не создавался, ключи и пароли не вводились. Это изображения интерфейса для навигации, не доказательство чистой установки или успешного подключения к ИИ.

- setup.jpg — регистрация с автоматически подставленным вымышленным кодом.
- setup-recovery.jpg — регистрация без кода, подсказка про ярлык.
- ai-settings.jpg — выбран OpenRouter, ключ ещё не введён.

При изменении этих экранов обновить изображения. Снимки Docker и системных окон Windows нужно снимать на соответствующих системах при приёмке; не заменять их макетами.
