# Установить MedScribe

MedScribe записывает речь, превращает её в текст и составляет черновик протокола. Вы проверяете и редактируете результат.

**Выберите свой компьютер:**

| [Windows →](install/WINDOWS.md) | [macOS →](install/MACOS.md) | [Linux →](install/LINUX.md) |
|---|---|---|

**До начала установки**

- Компьютер: от 16 ГБ оперативной памяти, 4 ядра процессора, не меньше 15 ГБ свободного места. Локальной языковой модели понадобится дополнительное место и память.
- Docker Desktop — программа, которая запускает службы MedScribe. Инструкция по её установке есть на странице вашей системы. MedScribe нужно выделить в Docker не меньше 8 ГБ памяти.
- Интернет: скачивается сама программа и около 5,6 ГБ для распознавания речи. Скорость зависит от соединения; не закрывайте компьютер и не переводите его в сон во время загрузки.
- MedScribe бесплатный. Для протокола нужен ИИ: внешний сервис со своим ключом (его использование может оплачиваться отдельно) **или** локальная модель. Подписка на чат-бот не обязательно включает API. [Как подключить ИИ →](CONNECT_AI.md)
- У Docker Desktop свои условия использования; проверьте их на странице загрузки, особенно для установки в организации.

**Путь до результата:** установка → аккаунт → подключение ИИ → [первая пробная запись](FIRST_PROTOCOL.md). До теста не нужны данные настоящего пациента.

Не нужно скачивать исходный код, открывать файлы `.env` или выбирать компоненты программы. После установки появится ярлык MedScribe.
