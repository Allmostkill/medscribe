# Установка на Linux

[← Выбор системы](../START.md)

Перед началом: от 16 ГБ памяти, 4 ядра и 15 ГБ свободного места. Для протокола понадобится ключ внешнего ИИ или отдельно установленная локальная модель. [Подробные требования](../START.md).

## 1. Подготовьте Docker

Установите и запустите [Docker Engine для вашего дистрибутива](https://docs.docker.com/engine/install/) с плагином Compose или [Docker Desktop](https://docs.docker.com/desktop/setup/install/linux/). Нужен Compose 2.24 или новее и не меньше 8 ГБ памяти для Docker.

**Ожидаемый результат:** команда `docker info` выполняется от вашего пользователя без ошибки доступа. Если это не так, завершите настройку по официальной инструкции Docker. Не запускайте установщик MedScribe через `sudo`.

## 2. Установите MedScribe

Откройте терминал, вставьте строку и нажмите Enter:

```sh
curl -fsSL https://raw.githubusercontent.com/Allmostkill/medscribe/main/scripts/install.sh | sh
```

**Ожидаемый результат:** шесть шагов установки, затем браузер со страницей создания аккаунта. Если браузер не открылся, откройте ссылку, которую напечатал установщик. Ссылку с кодом никому не отправляйте.

После обрыва загрузки или исправления ошибки ту же строку можно выполнить снова. Данные не нужно удалять.

## 3. Создайте аккаунт и подключите ИИ

Заполните форму регистрации. После создания аккаунта [подключите ИИ](../CONNECT_AI.md), дождитесь готовности распознавания и сделайте [пробную запись](../FIRST_PROTOCOL.md).

**Завтра:** запускайте MedScribe из меню приложений. Docker должен быть запущен; ярлык Linux сам системную службу Docker не запускает.

Если вы устанавливаете программу на отдельный сервер, используйте [инструкцию для сервера с HTTPS](../GUIDE.md#34-установка-на-сервер-с-доменом-и-https). Обычный адрес `http://IP` не подходит для записи микрофона с другого компьютера.
